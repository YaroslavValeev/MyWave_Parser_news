# Серверный пакет manual-final-post

Зависит от ручного редактора финального поста (PR #31) и установленного
пакета runtime-alignment (PR #30). Базовый профиль — 105 файлов, подтверждённых
аудитом сервера 09.10.2026. Новый модуль увеличивает проверяемый профиль до 106.

Пакет изменяет шесть существующих файлов: repository, publication, keyboards,
router, views и offline smoke; добавляет telegram_bot/final_post_edit.py.
100 остальных файлов защищены хешами. Исходники берутся из закреплённого
коммита; установщик, манифест и patch проверяются SHA-256.

До замены выполняются staging и сценарий в временной SQLite: ручной текст
доходит до подменённого транспорта публикации, а изменение источника блокирует
отправку. Реальных OpenAI/Telegram запросов нет. Конфигурация модели, proxy,
источников и Git-каталог сервера сохраняются. Миграции и pip не запускаются.

Перед применением установщик останавливает parser-news-bot, повторно проверяет
файлы и состояние карточек 626/649, сохраняет код и SQLite в каталоге
/opt/bot3/backups/editorial-release-*. После атомарной замены повторяет сценарий,
проверяет файлы и службу. Ошибка запускает откат кода; существующие данные не
перезаписываются резервной копией БД.

Применение из /opt/bot3/parser-new-bot: загрузите установщик по полному commit
SHA, проверьте его SHA-256, затем запустите venv/bin/python -B SCRIPT --apply
--package manual-final-post --package-ref COMMIT. Режим --check выполняет
проверки без изменения сервера. Для отката тот же установщик принимает
--rollback-dir с фактическим каталогом резервной копии из успешного вывода.

Проверка после установки: служба active/running, финальный аудит 106/106,
модель gpt-4o-mini и разрешённый источник wakeflot.ru. В Telegram заново
откройте карточку /item 626: появится «✏️ Редактировать финальный пост».
Уже отправленные сообщения не меняют старую клавиатуру автоматически.
Реальная тестовая публикация остаётся отложенной по указанию пользователя.
