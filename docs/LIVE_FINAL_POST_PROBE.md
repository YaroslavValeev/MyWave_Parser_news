# Проверка доставки ручной версии в личный Telegram-чат

Инструмент scripts/probe_live_final_post.py предназначен для одного
разрешённого пользователем тестового текстового поста. Требует установленный
редактор из PR #32, активную службу parser-news-bot и положительный chat_id
личного чата. Перед отправкой проверяет 106 файлов исполнения, модель
gpt-4o-mini, адресата через getChat и привязку саммари выбранной карточки к
ожидаемой статье. Без --send работает без Telegram-запросов.

Рабочая SQLite открывается в режиме только чтения. Источник и саммари
копируются в отдельную временную SQLite; идентификатор источника и маркеры
привязки пересчитываются для этой копии. Инструмент сохраняет тестовый ручной
текст через тот же метод репозитория, ставит только временную запись в очередь
и использует PublicationService для проверки политики и формирования
отправляемого тела. В текст включена явная пометка «ТЕСТ». Ссылки добавляются
обычным форматом публикации. Отправляется одно текстовое сообщение.

Временный адаптер сохраняет результат в тестовой SQLite без вызовов сайта и
Google Sheets; медиа не подгружается. Это проверка доставки финального текста,
а не живой проверки загрузки обложки, распознавания голоса или UI действий
пользователя. Они проверены отдельно в автоматических сценариях.

Пример запуска из /opt/bot3/parser-new-bot: venv/bin/python -B SCRIPT
--chat-id PERSONAL_CHAT_ID --expected-url ARTICLE_URL --send.
Полный commit SHA и SHA-256 скрипта нужно проверить перед запуском.

Перед Telegram-запросом создаётся закрытый файл результата в
/opt/bot3/backups/live-final-post-*.json. Подтверждённая отправка сохраняет
message_id и результат сравнения возвращённого текста. Повторный запуск того
же теста возвращает already_sent и не отправляет ещё одно сообщение.
После таймаута доставка может быть неизвестной; автоматическое повторение
заблокировано. Проверьте личный чат и файл результата перед дальнейшими
действиями. Карточки 626/649 и рабочая очередь публикации не изменяются.

Успех: live_probe=ok, manual_text_verified=true,
production_records_unchanged=true, production_database_writes=0,
real_openai_requests=0, telegram_posts=1. Telegram Bot API подтверждает
доставку сообщения в чат; прочтение пользователем проверяется им самим.
