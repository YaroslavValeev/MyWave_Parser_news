# Текст статьи по ссылке

Модель остаётся `gpt-4o-mini`. Для поста, состоящего из одной ссылки,
NLP может загрузить текст этой статьи. Исходный `items.content`, медиа и
комментарий владельца сохраняются. Отклонённые и опубликованные записи
не перегенерируются, в том числе запись 649.

Ссылка `[подпись](URL)` разбирается по адресу назначения, а повторённый
адрес `[URL](URL)` считается одной ссылкой. Сбалансированные скобки в
пути URL сохраняются. Если при включённой загрузке пост явно ссылается
на одну статью разрешённого сайта, факты берутся из проверенного текста
статьи. Подпись и пересказ поста сохраняются отдельно и не заменяют
статью при отказе загрузки. До извлечения старое саммари этой карточки
блокируется; после извлечения требуется соответствие SHA-256 статье.
Другие сайты и выключенный флаг сохраняют прежнюю обработку текста.

## Порядок включения

1. Сначала установить проверенный код с резервной копией файлов и SQLite.
   Не выполнять checkout поверх изменённого серверного дерева.
2. Применить миграцию `004_source_context.sql` через штатный
   `initialize_database`. Она добавляет nullable `items.source_context`.
3. Проверить доступ к конкретной статье без БД, модели и Telegram:

   ```bash
   cd /opt/bot3/parser-new-bot
   venv/bin/python -B scripts/probe_source_article.py https://wakeflot.ru/news/1785 --host wakeflot.ru
   ```

4. В серверном `.env` установить:

   ```dotenv
   SOURCE_ARTICLE_FETCH_ENABLED=true
   SOURCE_ARTICLE_ALLOWED_HOSTS=wakeflot.ru
   ```

5. Перезапустить действующий `parser-news-bot`, проверить состояние,
   затем перегенерировать одну новую карточку со ссылкой через Owner-бот.
   Не отправлять публикацию до ручной сверки текста с источником.

Флаг по умолчанию выключен, список хостов пуст. Дополнительные сайты
нужно проверять по одному и добавлять точными именами через запятую.

## Ограничения и проверка

Принимается одна явная HTTP(S)-ссылка. Переходы разрешены только на тот
же хост и путь статьи. Внутренние IP, бинарный контент, неоднозначные
заголовки, несовпадение canonical и слишком короткий текст блокируются.
Лимиты: 512 KiB HTML, 200–30000 символов текста, 15 секунд загрузки.
Отбирается явный контейнер статьи; навигация, формы и соседние новости
не используются. Неподдерживаемая страница остаётся на ручном ревью.

Доказательство включает URL, время, SHA-256 исходной записи, текста и HTML.
Изменение поста/ссылки делает доказательство недействительным. Старое NLP
без привязки к этой статье не допускается в карточку или публикацию.
Сохранение результатов атомарно проверяет источник и статус, сохраняя
параллельное отклонение владельцем.

Локально: `python -m pytest -q tests/test_source_article.py tests/test_nlp_source_context.py tests/test_item_context.py tests/test_owner_content.py`.
В Docker запускать ту же выборку и обязательный CI-набор в отдельном
контейнере с копией кода и временной SQLite, без настоящих ключей/токенов.

## Откат

Выключить флаг и вернуть сохранённые версии файлов, перезапустить и
проверить сервис. Nullable колонку и доказательства сохранить: прежний
код их игнорирует. Откат БД целиком не выполнять после новых действий
владельца. Код не меняет статусы 649 и не отправляет сообщения сам.
