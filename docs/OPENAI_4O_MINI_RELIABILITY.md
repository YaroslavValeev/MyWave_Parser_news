# Надёжность задач с gpt-4o-mini

Модель сохраняется. Текстовые вызовы остаются на Chat Completions:
температура 0.2, максимум 1600 выходных токенов, одна SDK-попытка повтора
после основной и общий дедлайн 90 секунд на вызов, включая повторы.
Настройки: `TEXT_MAX_COMPLETION_TOKENS`, `TEXT_MAX_RETRIES` (0–2),
`TEXT_TIMEOUT_SECONDS`. Нет скрытого переключения текстовой модели.

Пустой, обрезанный и отказной ответ не считается готовым текстом.
В журнале доступны модель, задержка, входные/выходные/кешированные токены
и тип ошибки; текст источника, API-ответ с ошибкой и ключ не выводятся.

Саммари требует русского языка и фактов источника. Если ответ остался
английским, выполняется один перевод. Повторная неудача оставляет запись
на ревью с диагностикой вместо придуманного типового саммари.
Названия брендов сохраняются; проверка языка эвристическая, поэтому
ручная проверка перед публикацией остаётся обязательной.

Для аудио fallback на `whisper-1` разрешён один раз только при машинном
коде `model_not_found` и другой исходной модели. Поток файла открывается
заново. Ошибки авторизации и прав не запускают fallback.

Локально и в отдельном Docker-контейнере:
`python -m pytest -q tests/test_openai_client.py tests/test_openai_text_reliability.py tests/test_openai_skip_moderation.py tests/test_nlp_source_context.py`.
Тесты SDK используют MockTransport; реальные генерации и отправка
Telegram не выполняются. Сервер использует OpenAI SDK 2.28.0; локальная
совместимость также проверяется с установленной версией 1.109.1.

Перед серверной установкой проверить хеши изменяемых файлов, сохранить
код и SQLite, убедиться в активном сервисе и текущей модели.
Откат: вернуть резервные версии клиента, настроек и pipeline,
перезапустить `parser-news-bot`. Миграций в этом изменении нет.

Семантика SDK и параметров сверена с [OpenAI Python API library](https://developers.openai.com/api/reference/python)
и [Create chat completion](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create).
