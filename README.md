# MyWave_Parser_News

MyWave_Parser_News — это Telegram-бот для парсинга новостей из различных источников (Telegram-каналы, RSS-ленты, YouTube, веб-сайты) с последующим анализом и публикацией в Telegram-канале.

## Функциональность
- **Парсинг новостей** из Telegram, RSS, YouTube и веб-сайтов.
- **Фильтрация контента** по ключевым словам: wakeboard, wakesurf, surf, wake, longboard, skim, foil.
- **Сохранение новостей** в Google Sheets.
- **Автоматическая публикация** новостей и генерация отчётов.
- Поддерживаемые команды: `/start`, `/parse`, `/publish`, `/addsource`, `/setfilters`, `/getcontacts`, `/report`.
